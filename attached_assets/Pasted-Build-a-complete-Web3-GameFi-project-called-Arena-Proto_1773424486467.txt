TOKEN CONTRACT — ArenaCoin

Create an ERC20 token using OpenZeppelin.

Name: ArenaCoin  
Symbol: ARENA  

Total supply:

1,000,000 tokens minted to deployer.

Functions:

mint(address to,uint256 amount)

burn(uint256 amount)

--------------------------------

NFT CONTRACT — ArenaFighterNFT

ERC721 fighter characters.

Name: Arena Fighter  
Symbol: AFIGHT  

Each fighter has attributes stored in a struct:

strength
speed
intelligence
wins
losses
rarity

Rarity tiers:

Common
Rare
Epic
Legendary

Stats generated pseudo-randomly.

Function:

mintFighter(address player)

--------------------------------

BATTLE ENGINE — ArenaBattle

ArenaBattle interacts with:

ArenaCoin
ArenaFighterNFT
ArenaRewardVault

Battle rules:

Entry fee:

10 ARENA tokens

Winner reward:

18 ARENA tokens

Burn:

2 ARENA tokens

Battle modes:

PvE
PvP

Emit event:

FightResult(address player,bool win,uint256 fighterId)

--------------------------------

STAKING CONTRACT — ArenaStaking

Players can stake ARENA tokens.

Functions:

stake(uint256 amount)
unstake()
claimRewards()

Rewards distributed daily.

--------------------------------

REWARD VAULT — ArenaRewardVault

Stores reward pool.

Functions:

depositRewards(uint256 amount)
withdrawRewards(uint256 amount)

--------------------------------

NFT MARKETPLACE — ArenaMarketplace

Players can trade fighter NFTs using ARENA tokens.

Functions:

listNFT
buyNFT
cancelListing

Marketplace fee:

2%

--------------------------------

LEADERBOARD — ArenaLeaderboard

Tracks player statistics:

totalWins
totalBattles
totalRewards

Function:

getTopPlayers()

README

Include instructions:

1 install dependencies

npm install

2 configure environment

.env

PRIVATE_KEY=
BASESCAN_API_KEY=

3 compile contracts

npx hardhat compile

4 deploy to Base Mainnet

npx hardhat run scripts/deploy.js --network base

5 verify contracts

npx hardhat verify --network base ADDRESS

6 run backend server

node backend/server.js

7 start frontend

npm run dev
